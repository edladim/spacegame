# Spacegame

Et romskip-skytespill laget med Python og Pygame som avsluttende IT2-prosjekt på videregående (2023/24).

## Om spillet

Du styrer et romskip og skyter ned fiender som faller nedover skjermen. Farten øker gradvis, og du kan plukke opp powerups for å skyte tre kuler samtidig. Highscoren lagres mellom øktene.

**Kontroller:**
- `WASD` — beveg romskipet
- `P` — skyt
- `R` — start på nytt etter game over

## Kom i gang

**Krav:** Python 3 og Pygame

```bash
pip install pygame
python game.py
```

## Teknologi

- Python 3
- Pygame
